# 河本大地 パーソナルトレーニング LP

ターゲット設計書をもとに制作した日本語のレスポンシブLPです。

## 開発

Node.js 22以降を推奨。

```sh
npm ci
npm run dev
```

## 本番ビルド

```sh
npm run build
npm run preview
```

静的ホスティングには `dist/` を配置してください。

## 公開前に確定する情報

- 体験・継続プランの料金、所要時間、回数
- 予約先URL（`index.html` の相談ボタンと `src/main.js` の準備中ダイアログを置き換える）
- 店舗名・所在地・営業時間、正式な資格表記
- 必要に応じてプライバシーポリシー、事業者情報
- トレーナー本人の写真と、使用許諾を確認した写真素材

写真はUnsplashのイメージ写真で、ご本人・店舗の写真ではありません。画像・Google Fontsの表示には外部通信が必要です。お客様の声・ビフォーアフターは、実際の掲載許諾済み事例が未提供のため掲載していません。予約や個人情報の送信機能は未接続です。

## 管理画面（microCMS）

連携設定は [content/README.md](content/README.md) を参照してください。未接続時は既存のLPを表示します。GitHub ActionsでAPIキーを安全に使用し、公開済みコンテンツのみを取得します。
